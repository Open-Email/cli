# CLI documentation

- Keep the README focused on installation, sign-in, and common tasks. Use plain
  language and short examples; link to guides for detailed workflows and edge cases.
- When commands, flags, defaults, authentication, or installation change, update
  the affected documentation in the same change. Update the README when setup or
  its examples change; use `docs/COOKBOOK.md`, `docs/AUTH.md`, and `docs/OUTPUT.md`
  for the detailed behavior.
- Check documented commands and flags against the current CLI help. Keep claims
  about output, pagination, and operating-system behavior specific to what the
  implementation supports.
